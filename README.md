# Tic Tac Toe

A simple browser-based Tic Tac Toe game built with HTML, CSS, and JavaScript.

## Features

- Two-player local mode
- Play against a bot mode
- Win detection and draw detection
- Responsive layout for desktop and mobile
- Clean, modern UI

## Play the game

Open `index.html` in your browser to start playing.

You can also serve the project locally with a simple static server if you prefer:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Project files

- `index.html` — page structure
- `styles.css` — game styling and responsive layout
- `script.js` — game logic and bot behavior

## How to play

1. Choose your mode: Two players or Vs bot.
2. Players take turns placing marks on the 3x3 board.
3. The first player to get three marks in a row wins.
4. Use the New round button to reset the board.
